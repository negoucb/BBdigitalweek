# BB Digital Week

Sistema web para gerenciamento e organização da **BB Digital Week**, desenvolvido em **React + Vite**. A plataforma permite administrar sessões, trilhas, atividades, palestrantes, espaços e horários do evento em uma interface moderna e intuitiva.

## 📋 Funcionalidades

### Dashboard

* Visão geral do evento
* Indicadores e métricas rápidas
* Navegação centralizada

### Cronograma

* Visualização da programação do evento
* Organização por horários
* Exibição de sessões e atividades por trilha

### Gestão de Conteúdo

* Cadastro de Sessões
* Cadastro de Trilhas
* Cadastro de Atividades
* Cadastro de Palestrantes
* Cadastro de Espaços
* Cadastro de Horários

### Fluxo de Aprovação

* Propostas permanecem em estado **"Em Andamento"**
* Aprovação realizada pelo organizador
* Controle do status dos conteúdos

### Recursos Adicionais

* Login de usuários
* Menu lateral de navegação
* Navbar com informações do usuário
* Exclusão de registros
* Alertas de similaridade utilizando IA
* Interface responsiva

## 🚀 Como Executar o Projeto

### Pré-requisitos

* Node.js 18+
* npm

### Instalação

```bash
git clone https://github.com/seu-usuario/bbdigitalweek.git

cd bbdigitalweek

npm install
```

### Executar em Desenvolvimento

```bash
npm run dev
```

O sistema estará disponível em:

```text
http://localhost:5173
```

### Gerar Build de Produção

```bash
npm run build
```

### Visualizar Build

```bash
npm run preview
```
